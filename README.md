Основные возможности

Управление списками
- Создание нескольких списков покупок
- Переключение между списками
Удаление списков с товарами
Работа с товарами
- Добавление товаров с названием, категорией, количеством и приоритетом
- Редактирование количества товаров
- Удаление товаров из списка
- Поиск товаров по названию и категории
Сравнение цен
- Добавление магазинов для сравнения цен
- Ввод цен для каждого товара в разных магазинах
- Автоматическое определение самого выгодного магазина
- Визуальное выделение минимальных и максимальных цен
Аналитика и статистика
- Общая статистика по списку покупок
- Распределение по категориям и приоритетам
- Прогресс заполнения цен
- История изменения цен по магазинам
- Расчет потенциальной экономии
Сортировка
- Сортировка по названию, категории, цене и приоритету
- Быстрый поиск по товарам
